### 核心结论
README 的"已完成"在**功能覆盖**上基本属实（代码很干净，全项目仅 2 处 TODO），但在**能力落地**上有 5 处断裂，其中 3 处是**静默错误**（不报错但结果错）：

1. **行/列级权限配置了不生效** —— `SysRowPolicy`/`SysColumnPolicy` 零外溢到查询链路，`PermissionApiClient` 4 个方法全是表级。README 却把它列为第一梯队核心特性。
2. **调度 DAG 依赖不生效** —— `schedule_job_dep` 只增删改查，`JobScheduler`/`JobExecutor` 从不读取 → 任务乱序跑出脏数据。
3. **REFRESH/SYNC/PUSH 三类任务假成功** —— `JobExecutor:121-125` 仅 log 后 `return 0`。
4. 项目组 17/18 端点无界面（后端 285 行真实实现裸奔）。
5. 通知仅站内信+邮件真发，钉钉/企微/短信/Webhook 零代码。
