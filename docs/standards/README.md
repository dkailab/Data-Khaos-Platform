# 国家数据技术文件摘要

本页提炼用户提供的 10 份 2025 年技术文件。国家数据局公开发布的六项 NDI 文件标注为试行。四项高质量数据集文件为全国数标委 TC609 技术文件，附件封面标注 2025-08-29 发布及实施。2026 年 4 月公开征求意见的国家标准包含同名或相关主题。项目采用附件版本作为参考基线，正式对接前按实际节点、合同或验收要求复核适用版本。以下章节号为附件正文。 [NDI 发布通知](https://www.nda.gov.cn/sjj/ywpd/szkjyjcss/0306/20250306180822001405764_pc.html) · [2026 年国家标准征求意见通知](https://www.nda.gov.cn/sjj/zwgk/tzgg/0407/20260407213420895658136_pc.html)

## 数据基础设施与跨域互通

| 原件 | 应读章节 | 对项目最重要的内容 |
| --- | --- | --- |
| NDI-TR-2025-01《参考架构》 | §5–7，附录 A | 用户视图区分参与方和活动，功能视图区分网络、算力、流通利用及横向能力。流通利用涉及接入连接器、业务节点、区域/行业功能节点和全域功能节点。按部署角色选能力。 |
| NDI-TR-2025-02《互联互通基本要求》 | §4–8，表 4 | 统一目录标识、身份登记和接口。区分数据登记、上架、目录上报/下发、发现和交互，也区分业务节点发现流程。§7 按调用方和提供方划分互通责任。§8 定义报文、版本、扩展和安全，包含节点证书认证、TLS 1.2 及以上、时间校验、完整性和审计。 |
| NDI-TR-2025-03《用户身份管理和接入规范》 | §5–9，规范性附录 A–C | 分别管理用户、接入连接器与平台身份。用户身份覆盖个人、法人或其他组织及其经办人。接入涉及注册、核验、登录与跨域身份互认，凭证和 Token 格式见附录。 |
| NDI-TR-2025-04《标识管理规范》 | §4–7 | 主体标识 18 位，平台和接入连接器 32 位，资源及产品 32～65 位。区分赋码方、类型、校验和解析规则。跨域解析可定位对象及状态。存量标识可按规则作为扩展码保留。 |
| NDI-TR-2025-05《接入连接器技术要求》 | §6–8，规范性附录 A–C | 基本能力覆盖身份认证、网络接入、交付、访问控制、日志、状态上报。另列目录服务、使用控制、隐私计算等扩展能力。互操作覆盖目录发现及详情、API 交付、批量数据流和传输协商。 |
| NDI-TR-2025-06《数据目录描述规范》 | §5–8，规范性附录 A–C | 区分数据资源目录和数据产品目录，并区分产品登记与上架。资源分类按行业和来源，产品分类按交付形式和行业。按字典校验必填、值域、状态和关联，账号、凭证和原始数据按授权交付。 |

对应原件可按编号在附件目录定位。接口字段、值域、必填条件和例外以对应章节、表格及附录为准。NDI-02 附录 A、B 分别提供隐私保护计算和区块链的建设参考。

## 高质量数据集

| 原件 | 应读章节 | 对项目最重要的内容 |
| --- | --- | --- |
| TC609-5-2025-01《建设指南》 | §4–10，图 1 | 明确目标模型和数据可用范围，规划并采集数据，做好预处理，按任务需要标注，最后通过模型验证把问题反馈给上游。管理训练、验证和测试子集的代表性和划分证据。 |
| TC609-5-2025-02《格式要求》 | §5–9，资料性附录 A | 分层描述数据元数据、内容元数据和标注元数据。按英文名、类型、值域、填充要求等属性建立 schema。顶层包含数据标识、内容、版本和许可等字段，逐项按原文判定必填性。数据标识引用 NDI-04。 |
| TC609-5-2025-03《分类指南》 | §4，表 1 | 区分通识、行业通识、行业专识。用知识内容、来源、时效性、标注人员、敏感程度、模型类型和主题范围记录分类依据。安全分类分级另有用途，应单独保留。 |
| TC609-5-2025-04《质量评测规范》 | §4–5，表 1–3，资料性附录 A | 说明文档、数据质量、模型应用三项各自至少 90 分。模型适配性按 §5.4.2 参与门控。无监督场景按原文处理不适用的标注子项和权重。附录 A 提供文本、图像、视频、音频的干净性参考指标。 |

评测应能还原数据版本、适用条款、采样范围、指标原值及分母、计算规则、证据与模型运行结果。平台 SQL 质量规则可以提供部分证据。完整评测还要有数据集说明、格式及内容检查和目标模型验证。
