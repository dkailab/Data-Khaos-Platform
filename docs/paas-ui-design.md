# Data Khaos PaaS 界面设计

以每天的开发和运维工作为中心。页面先回答跑了什么、哪个节点异常、影响哪些产出、可以执行什么操作。视觉采用浅灰白导航与内容面、雾灰画布和低饱和浅蓝。留白、边界和字号承担视觉层级，颜色优先传达操作与状态。

## 素材包与预览

- [主题变量](../data-khaos-web/src/paas-ui/tokens.css)统一颜色、间距、边界、字体、焦点及 Element Plus 主色。将 `.dk-paas` 放在实际使用该主题的 PaaS 页面或布局容器上。
- [DkButton](../data-khaos-web/src/paas-ui/DkButton.vue)提供主操作、次操作和行内操作，支持左侧图标、加载及禁用。[DkStatus](../data-khaos-web/src/paas-ui/DkStatus.vue)提供成功、运行中、失败、排队中和阻断。[DkPageHeader](../data-khaos-web/src/paas-ui/DkPageHeader.vue)提供页面标题、说明及操作区。
- 图标复用仓库现有的 `@element-plus/icons-vue`（MIT，许可证随依赖分发）。表格、图表、状态点和链路皆为代码素材。系统字体本机渲染。截图用于设计交接，交互界面可从源码运行。

在 `data-khaos-web` 运行 `npm run dev`，打开开发服务器的 `/paas-preview.html`。独立样板可从质量告警筛到失败实例，按负责人和状态查询，查看执行日志和产出影响。趋势支持切换周期和查看单日计数。它使用明确标注的示例数据。迁移生产页面时从实际 API 派生指标、图表与状态，生产门户通过同一套主题和组件呈现。

## 门户与工作区

- `/dashboard` 展示产品介绍和工作区入口，由 `Layout.vue` 提供公共壳。左上角「产品服务」展开多栏分类目录，支持搜索。功能与可见性来自 `modules/registry.ts` 和 `modules/workspaces.ts`。
- 进入业务工作区后，左侧仅显示当前工作区菜单，支持整栏收起和分组折叠。资产详情、仪表板详情及工作流编辑页的深链接应定位到归属工作区。
- 数据地图属于「数据资产」。`/assets?q=关键词` 列出可见的表，`/assets/tables/:tableId` 展示字段与直接血缘。保持关键词和分页回跳。旧搜索路由转到数据地图。
- 数据地图按显式 SELECT/ALL 表授权过滤目录、字段和血缘邻居。生产实例、质量结果和指标仅在有真实关联时显示。旧元数据管理接口沿用各自权限行为。
- 列表先显示筛选和表格，再提供分页；详情先显示资源、标识与状态，再展示关联记录；SQL 和 DAG 编辑器可用宽屏布局。

## 作业开发工作台

门户从「作业开发」进入 `/jobs`。开发者先选项目，再从左侧目录打开实时作业、离线作业或 OneSQL 查询。项目保存在 `project` 查询参数，切页与浏览器回退保持上下文。实时计算的运行值守保留专门入口，主要处理作业告警、检查点和恢复。数据源管理继续作为数据接入入口，离线编辑器列出当前项目已绑定的数据源。OneSQL 使用现有查询权限和库表目录。

| 工作区 | 当前可复用 | 首版界面 |
| --- | --- | --- |
| 实时作业 | Flink SQL/JAR、函数库、版本、引擎校验、提交与检查点 | SQL 作业可按流式和批处理筛选，版本详情可校验并查看运行。 |
| 离线开发 | DAG、SQL 节点、版本快照、调度和按业务日补数 | 工作流目录、实例与调度的关联入口。批次实例展示业务日期与失败节点。 |
| OneSQL 取数 | 数据库对象、查询结果、执行计划和历史 | 左侧切换库表与历史，中间运行整段或选中的 SQL，底部查看本次执行、分页结果和执行计划。CSV 导出本次返回的全部行。 |

布局采用 Data Khaos 浅蓝主题。左侧保留可折叠的项目作业目录与已授权数据库对象，中间显示 SQL 或 DAG，底部显示当前操作对应的查询结果、编译结果或运行日志。当前工作台已统一入口、项目上下文和返回路径，复用 SQL、DAG 和运行接口。SQL 作业使用全屏多标签编辑、未保存提示和底部结果面板，支持历史差异与回滚。目录按作业类型分组，仓库分层依据已登记的资产关系呈现。

首页按运行场景组织作业。实时和离线各有 SQL 作业及程序作业入口，调度工作流归离线作业，两类共用函数库。卡片在选定项目后显示真实数量，空列表显示 0，接口失败时显示读取失败。保存、校验、版本和运行记录使用一致的操作位置。作业类型表达业务运行方式，计算引擎由项目运行环境决定，版本和运维详情可以展示实际引擎。执行契约由作业类型决定：Flink 流式作业持续运行，使用检查点和保存点恢复；Flink 批作业使用同一 SQL 引擎跑有界输入；离线工作流由调度触发，支持任务依赖、业务日期和补数。OneSQL 用来交互查数及验证产出，其查询历史与生产作业版本各自保留。

首个验收使用同一项目的订单链路。打开实时 SQL 校验固定版本并检查 CDC 产出，打开离线工作流按同一业务日期补算，再在 OneSQL 核对 ADS。切换项目后重新检查作业、数据源和发布权限。保留实时计算与工作流旧链接，覆盖返回浏览器、直达历史版本、项目切换和无权限反馈。 [实时数仓样例与验收](paas/realtime-warehouse.md)

## 运维工作流参考

- DataWind 的监控管理面向项目，按名称、状态、所有者等查找规则，并依据角色授予查看或管理能力。Data Khaos 将这套信息组织用于项目内的监控规则与告警记录。运行实例列表独立展示运行状态、业务日期、负责人、触发方式和耗时。 [火山引擎监控管理](https://docs.volcengine.com/docs/Datawindprivatization/Monitoringmanagement?lang=zh)
- DataWind 的任务运维从失败概览进入已筛选的实例并查看日志。Data Khaos 采用「质量告警 → 失败实例 → 节点日志与下游产出」作为首期演示，后续在真实运行详情关联 Run ID 和目标分区。 [火山引擎运维管理](https://docs.volcengine.com/docs/Datawindprivatization/Operationsmanagement?lang=zh)
- 运行日志用于排障，操作审计记录谁在何时修改规则、重跑或补数。实际接入时分别执行权限校验，并将操作记录关联到对应实例。 [火山引擎操作日志](https://docs.volcengine.com/docs/datawind-privatization/operation-log?lang=zh)

## 视觉与交互约定

| 元素 | 约定 |
| --- | --- |
| 色彩 | 工作区与导航使用浅灰白，浅蓝用于选中态、链接和主操作。成功、失败及阻断使用各自的语义色。 |
| 页面 | 背景 `--dk-canvas`，面板使用 `.dk-panel`。常用间距 8、12、16、24、32px。圆角统一为控件 8px、面板 10px。 |
| 字体 | 中文使用系统字体，页面标题 27–36px，正文 14px，数据密集的表格可用 12–13px。时间与数值使用 `.dk-numeric`，技术标识和日志使用 `.dk-mono`。 |
| 按钮 | 一个操作区保留一个明显主操作。次操作用描边、行内查看用 quiet。危险操作沿用现有确认流程和失败反馈。图标按钮提供可读名称。 |
| 状态 | 优先使用文字与语义色同时表达。运行中、排队、失败和阻断有独立语义，前端根据实际响应映射。未知值保留可识别文字。 |
| 表格与图 | 主体列和状态靠前，时间注明时区，数值在数据表中对齐。长 ID 在详情中可查看完整值。图表保留单位、时间范围及键盘能访问的数值。窄屏允许表格容器横向滚动。 |
| 页面反馈 | 检查加载、无数据、筛选无结果、接口失败、无权限和禁用情况。详情关闭应回到触发按钮，主要操作支持可见键盘焦点。 |

## 交付验收

开发完成后对照运行概览检查组件、布局及状态语义。运行 `npm run build`，检查桌面和窄屏，并验证真实数据加载、筛选、失败和恢复路径。提交说明包含页面入口、使用的共享组件、用例结果，以及需要保留的视觉差异。
